# Reserva de Canchas

Aplicación web para la gestión y reserva de canchas deportivas. El sistema permite a los jugadores registrarse, consultar complejos y canchas disponibles, seleccionar horarios y realizar reservas, mientras que los administradores pueden gestionar la oferta de canchas y sus horarios.

El proyecto se desarrolla como un **MVP**, con foco en implementar los flujos principales de reserva y gestión, manteniendo un alcance acotado.

### Stack tecnológico

**Frontend:** React, Next.js, TypeScript y Tailwind CSS.

**Backend:** Node.js, NestJS y TypeScript.

**Base de datos:** PostgreSQL, utilizando Prisma como ORM.

**Infraestructura:** Docker y Git/GitHub.
